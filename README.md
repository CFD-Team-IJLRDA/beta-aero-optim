## beta-aero-optim — branch `emanuele-openfoam-backend`

Shape optimisation of the **LRN-OGV cascade** (low-Reynolds-number outlet guide vane) of the EU project
**SciFiTurbo**, with **OpenFOAM** as the RANS solver and a **neural-field surrogate** of the flow.
This branch is a fork of the open-source framework [AERO-Optim](https://github.com/mschouler/aero-optim) (M. Schouler),
whose [documentation](https://mschouler.github.io/aero-optim/) still describes the generic parts (FFD, meshing, `inspyred`/`pymoo` optimisers).

### What the branch adds
| step | what | where |
|---|---|---|
| RANS solver | OpenFOAM v2406, `rhoSimpleFoam` with k-ω SST + Langtry–Menter transition; one cascade passage, 3 operating points (ADP 43°, OP1 48°, OP2 38°); mixed-out loss and outflow angle on two measurement planes; run-quality check of the time-averaged QoIs | `aero_optim/simulator/openfoam.py`, `cascade_qoi.py`, `cascade_batch.py`; case template in `examples/LRN-OGV_OpenFOAM/case_template/` |
| mesh | gmsh template of one pitch (quad boundary layer, structured wake block), rebuilt for every blade | `aero_optim/mesh/foam_cascade_mesh.py`, `aero_optim/mesh/templates/` |
| shapes | DLR's BladeGen (13 parameters, Latin hypercube) reduced to **5 POD modes** (99.7 % of the shape variance); geometric constraints of Ciarlatani et al. (GT2026-178703) + a "BladeGen family" constraint | `aero_optim/shape/bladegen_pod.py`; constraints in `aero_optim/optim/cascade_foam.py` |
| design of experiments | 1000 BladeGen blades × 3 operating points, resumable and splittable across machines (`--shard`) | `doe` command, `aero_optim/main/doe.py` |
| brute-force optimisation | NSGA-II (pymoo) on the 5 POD coefficients, one RANS evaluation per candidate; two objectives L_ADP and L_OP = (w_OP1 + w_OP2)/2, geometric and outflow-angle constraints | `optim-foam` command, `aero_optim/optim/cascade_foam.py` |
| surrogate | implicit neural representation of the flow fields on a reference domain (periodic re-cut + RBF morphing + balancing), ensemble of 3 networks; GP baseline; NSGA-II and gradient-based (SLSQP, autodiff) optimisation on the surrogate with CFD verification; hyperparameter search on Jean Zay | `aero_optim/surrogate/`, `examples/LRN-OGV_OpenFOAM/surrogate/` (README there) |

The results (meshes, DoE, optimisations, surrogate study) are summarised in the report
`beta-aero-optim-runs/report_2026_11/report.pdf`.

### Code and data
The repository holds code only. Runs and data live in a separate folder, by default `/mnt/Data_B/beta-aero-optim-runs`
(override with `AERO_RUNS`; the surrogate's work folder with `SURROGATE_WORK`). That folder has its own `DIARY.md` (what was
done when) and `INDEX.json` (where things are, generated by `examples/LRN-OGV_OpenFOAM/runs_index.py`).

### Quick start
```sh
pip install -e .                         # Python >= 3.10; + ".[surrogate]" for the neural surrogate (torch, scikit-learn, optuna)
source /usr/lib/openfoam/openfoam2406/etc/bashrc
cd examples/LRN-OGV_OpenFOAM
doe -c openfoam_config.json --pilot 4    # a few DoE blades at the 3 operating points
optim-foam -c openfoam_config.json       # NSGA-II with one RANS run per candidate (resumable: rerun the same command)
```
The `"optim"` block of the config sets the population, generations, constraints, solver processes at once (`budget`) and the
initial population (`init`: best DoE blades, random DoE blades, or a new BladeGen Latin hypercube).

### Status (November 2026)
- OpenFOAM validated against LES on the baseline blade (closer to LES than the former RANS solver, WOLF, at all 3 points).
- Brute-force RANS optimisation: about −11 % on L_ADP or −7 % on L_OP, limited by the blade-area constraint.
- Neural surrogate: same front quality as the brute force with about half the CFD runs at ~100 CFD blades; no saving from ~200.
- Next: autoencoder-based shape reduction from all 21 BladeGen parameters, then multi-fidelity with LES in the loop.
